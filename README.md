# Week 2: Responsive Portfolio Website

## Project Description
Personal portfolio website made to practice HTML and CSS. It includes a home page, About page, Projects page, and Box Model practice page.

## Technologies Used
- HTML5
- CSS3

## Features
- Flexbox navigation.
- Responsive project grid: one column on phones, two on tablets, and three on desktop screens.
- Portfolio images and hover styling.

## What i Learned
- I learned to use colors, fonts, and spacing consistently.

## Challenges Faced
flex box an css grid

linking css files across pages
